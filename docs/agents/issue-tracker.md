# Issue tracker: Local Markdown

Issues and specifications for this repository live as Markdown files in `docs/tickets/`.

## Conventions

- One feature specification is a Markdown file in `docs/tickets/`.
- Implementation tickets are individual files named `NN-<slug>.md`, numbered in dependency order.
- Triage state is recorded as a `Status:` line near the top of each ticket file. See `triage-labels.md` for the role strings.
- Comments and decision history append under a `## Comments` heading when needed.

## When a skill says "publish to the issue tracker"

Create the feature specification or implementation ticket directly in `docs/tickets/`.

## When a skill says "fetch the relevant ticket"

Read the referenced file from `docs/tickets/`.
